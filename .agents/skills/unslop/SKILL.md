# Unslop

1. Scan text and code comments for AI tells: vague attributions, superficial -ing clauses, throat-clearing intros, and repetitive summaries.
2. Remove filler, passive voice, and conversational bloat.
3. State facts, changes, and instructions directly and concisely.
4. Retain technical precision, file links, concrete numbers, and reproduction steps.
5. Audit the final text: ensure every sentence delivers direct information.
