# Runtime forensics

1. Define the live symptom and the shortest observation window that captures it.
2. Instrument the real process or surface with the least invasive probes that distinguish competing causes.
3. Collect runtime evidence and align events on one timeline.
4. Narrow to a causal mechanism. Run one perturbation or counterfactual check when possible.
5. Deliver a diagnosis and confidence level. Do not silently turn the diagnostic task into a fix.
