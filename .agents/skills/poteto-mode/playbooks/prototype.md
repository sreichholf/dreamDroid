# Prototype

1. Write the decision the prototype must settle and the observable result that would favor each option.
2. Build the cheapest faithful sketch. For a contested design, create 2-3 materially different variants rather than polishing one.
3. Run or inspect the variants on the real or closest meaningful surface.
4. Compare results against the decision criteria, including costs that would survive into production.
5. Choose or reject based on evidence. Delete or clearly quarantine throwaway code unless the user asks to keep it.
